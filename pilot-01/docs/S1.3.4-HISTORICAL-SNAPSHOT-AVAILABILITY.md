# S1.3.4 — Historical Snapshot Availability Evidence

Status: IMPLEMENTED / CI PENDING

## Purpose

This gate operationalizes Implementation Freeze IF-01 for the first four verified OpenAI and Anthropic model snapshots. It separates exact snapshot identity from whether that exact snapshot can still be executed or otherwise supported by admissible historical evidence.

## IF-01 rule

A confirmatory historical observation may use only:

1. an exact immutable provider snapshot that is currently callable and independently verified; or
2. a sufficient archived historical observation tied to the exact snapshot.

If neither path exists, the observation remains `HISTORICAL_SNAPSHOT_UNAVAILABLE`. A rolling alias, successor model, or present-day replacement MUST NOT be substituted.

## Interpretation boundary

`historical_snapshot_unavailable` in this registry means the exact model cannot currently be re-run through the provider API on the evidence date. It does **not** prove that no valid archived historical benchmark observation exists. If an independently verifiable archived observation is later found, it may be added as a separate evidence record without rewriting this current-availability observation.

Likewise, `callable_exact` establishes exact current callability under IF-01. It does not authorize use of a rolling alias, does not prove the model was callable on every prior date, and does not itself provide historical benchmark outcomes.

## Consequence for the S1.2.5 micro-backtest

The two OpenAI exact snapshots can proceed to the later execution/evaluation layer once pricing evidence and observation-date rules are satisfied. The two Anthropic snapshots cannot be reconstructed by calling current replacement models. Their historical cells remain unavailable unless admissible archived observations are located.

## Research-integrity rules

- Never backcast with a successor model.
- Never convert a family alias into an exact historical snapshot without first-party evidence.
- Never treat deprecation or retirement metadata as a benchmark score.
- Preserve unavailable cells as unavailable rather than imputing model performance.
- New archived evidence must be additive and independently traceable.
