# Pilot 01 Data

This directory is reserved for datasets used by DACDM Pilot 01.

Planned separation:

- `raw/` — source observations preserved without analytical transformation.
- `processed/` — cleaned and standardized observations.
- `derived/` — analysis-ready panels and derived variables.

## Required provenance

Each observation should retain, where applicable: task identifier, task source, task release date, execution date, model and model tier, quality result, input/output/reasoning tokens, tool calls, retries, latency, API cost, hardware-performance index, contamination flag, source reference, and notes.

Do not commit copyrighted benchmark content or restricted provider telemetry unless redistribution is permitted. Where raw task text cannot be redistributed, store identifiers, hashes, provenance, and reproducible retrieval instructions instead.

No empirical dataset has been committed yet.
